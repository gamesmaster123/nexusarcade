How to Get a Free Web Link

Since `index.html` is stored locally on your computer, opening it shows a local file path (`file:///C:/...`). To turn it into a public live `https://` web link for free:

Option 1: Netlify Drop (Easiest - 10 Seconds)

  1. Go to app.netlify.com/drop in your browser.
  2. Drag and drop the folder containing your index.html onto the screen.
  3. Netlify will instantly generate a free live web link (e.g. https://nexus-arcade.netlify.app)!

Option 2: GitHub Pages (Free Permanent Link)

  1. Create a free account on GitHub.com.
  2. Create a new public repository named arcade.
  3. Upload your index.html file.
  4. Go to Settings -> Pages, set branch to main, and click Save. Your web link will be ready in 1 minute!
